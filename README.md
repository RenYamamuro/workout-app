# 筋トレ記録アプリ（v1）

エニタイムフィットネス船橋二和東店の設備に合わせた A/B/C 3分割メニューを、
その場で記録するための自分用Webアプリ。素の HTML + CSS + JavaScript の1ファイル構成で、
データはブラウザの `localStorage` に保存される（サーバー不要・ログイン不要）。

## できること（MVP）

1. **メニュー選択** — A → B → C の循環。前回の記録から「次はこれ」を自動表示
2. **記録** — 種目ごとに重量とレップ数を入力して保存。セットの追加・削除も可能
3. **前回の記録を種目の横に表示** ← 本体。重量の初期値も前回値が入る

4. **種目ごとの図解** — 19種目それぞれにマシンの図（SVG）を表示。タップで拡大
5. **実物の写真を登録** — 拡大表示から自分で撮った写真を登録すると、図の代わりに表示される

おまけ：
- 目標レップを全セット達成すると「次回は2.5〜5kg上げてOK」と表示（漸進性過負荷の判断用）
- 履歴一覧（日付・メニュー・総挙上量・メモ）と、記録の削除

### 図解と写真について

図解は手描きのSVG（`index.html` の `ART`）で、外部の画像は一切読み込んでいない。
灰色＝マシンの骨格、白＝人、青＝動く部分・負荷 という描き分け。

実物の写真はジムで撮って登録するのが一番わかりやすい。登録した写真は
長辺640pxのJPEGに縮小してから `localStorage`（キー `workout-photos-v1`）に保存される。
容量は全体で5MB程度が上限なので、入りきらない場合は使わない種目の写真を削除する。

## 使い方

Macでそのまま開くだけなら `index.html` をダブルクリックでも動く。
iPhoneから使う場合はローカルサーバー経由が確実。

```bash
python3 -m http.server 5173
```

- Mac: http://localhost:5173
- iPhone（同じWi-Fi）: `http://<MacのIPアドレス>:5173`
  IPアドレスは `ipconfig getifaddr en0` で確認できる

### ホーム画面に追加

iPhoneのSafariで開く → 共有ボタン → 「ホーム画面に追加」。
アドレスバーなしのアプリのように起動する。

※ ホーム画面から常時使いたい場合は、Macを起動しなくて済むように
GitHub Pages や Netlify などに置くのが次のステップ。

## ファイル構成

- `index.html` — アプリ本体（HTML / CSS / JS すべて）
  - `MENUS` … 種目マスタ。種目の追加・変更はここを編集する
  - `STORAGE_KEY` … localStorage のキー
  - 画面は `renderHome()` / `renderWorkout()` / `renderHistory()` の3つ

## データ構造

```js
{
  id: 1756... ,            // 保存時刻（削除の識別に使用）
  date: "2026-08-25",
  menu: "A",
  memo: "脚に筋肉痛が残っていたので軽め",
  exercises: [
    {
      name: "スミスマシンベンチプレス",
      sets: [
        { weight: 30, reps: 10 },   // weight: null は自重
        { weight: 30, reps: 10 },
        { weight: 30, reps: 8 }
      ]
    }
  ]
}
```

## 注意

- データはブラウザごとに保存される。Safariの履歴・サイトデータを消すと記録も消える
- MacとiPhoneの間で同期はされない（v2でクラウド同期を検討）
